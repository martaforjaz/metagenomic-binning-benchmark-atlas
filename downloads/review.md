# Structured literature scoping review

Search date and coverage boundary: **5 November 2026**. This is a bounded, repository-assisted scoping review, not a systematic review and not an exhaustive survey through this date. Thirteen article citations are verified against 11 primary author/community repositories. Most article full texts and supplements could not be accessed under the current network policy. Consequently this release does not claim a completed publication-level reporting audit.

## Questions and selection

The four questions are: which datasets/protocols are used; what documentation supports reproduction; what enables fair comparison; and whether a small common-protocol evaluation can be reproduced.

A new search was attempted with `metagenomic binning` via Europe PMC's REST search (`pageSize=2`, JSON); the endpoint was denied by the outbound proxy. A direct CAMI II publisher request was likewise denied before retrieval. No result counts or exclusion counts are inferred from these failures. The reproducible executed strategy then used primary-repository inspection and citation snowballing, starting independently with CAMI/AMBER, RasmussenLab/Vamb and BigDataBiology/SemiBin, and expanding to graph, strain and contrastive-learning tools. Search expressions within retrieved documentation included `doi`, `citation`, `CAMI`, `dataset`, `benchmark`, and `202[456]`. The selected source commits, URLs, dates and short evidence excerpts are in `sources.csv`. The unsuccessful guessed repository URLs for `ilkerkesen/COMEBin` and `metabat2/metabat2` were discovery failures, not excluded papers.

Include a resource when it directly addresses genome/contig binning, common benchmark generation, evaluation, graph/strain resolution or current representation learning, and a primary repository can be inspected. Prefer central shared benchmarks and at least one example per relevant method family, then recent linked extensions. Exclude taxonomy-only classification as a main study, unverified rankings, unrelated reviews and duplicate preprint/journal records. Stop after this thematic subset and one round of linked current-resource discovery; do not imply saturation. Resources requiring inaccessible external data remain access-unconfirmed.

## Evidence synthesis

CAMI I [cami1] and CAMI II [cami2] supply community benchmark contexts. CAMISIM [camisim] makes the simulated community, abundance model and sequencing configuration part of the dataset definition. A release name alone is insufficient to identify the exact challenge input. Toy and challenge data, raw reads and gold-standard assemblies must be distinguished.

Composition/coverage baselines remain relevant controls: they separate feature availability from representation/model effects. The common-protocol demonstration here uses archived CONCOCT and MaxBin outputs. MetaBinner [metabinner] adds an ensemble approach; its current author citation is a 2023 journal paper rather than the 2021 preprint used in the workbook. No performance claim from its README is treated as independently verified evidence.

GraphBin [graphbin] refines an initial binning with assembly connectivity. MetaCoAG [metacoag] combines graph structure, coverage, composition and markers. GraphMB [graphmb] explicitly targets long-read assemblies and describes Flye 2.9 graph information, coverage and optional marker inputs. These methods do not receive interchangeable inputs: comparing them against sequence-only methods requires recording graph generation and reference-derived features. The STRONG primary repository describes core-gene variants and co-occurrence across samples, addressing strain resolution rather than simply partitioning contigs into species-level MAGs. Its paper metadata has not been newly full-text reviewed in this release.

Vamb [vamb] learns from composition and abundance using a variational autoencoder. Avamb [avamb] combines adversarial and variational approaches; the current Vamb README labels it obsolete, illustrating why paper version and current software version must be separated. SemiBin [semibin] uses semi-supervised information; SemiBin2 [semibin2] describes self-supervised contrastive learning and short-/long-read algorithms. COMEBin [comebin], published in 2024, uses multi-view contrastive learning; its README describes contig/BAM inputs and a demo. Training constraints, multiple-sample abundance, reference annotations and augmentations are protocol variables, not incidental details.

The current Vamb README links TaxVamb with DOI `10.1038/s41587-026-03098-0`. This is a verified **repository citation discovery**, not a completed review of a 2026 article; title, full text, publication date and datasets have not been independently extracted. It is recorded in `current_resources.csv`, outside the 13 article count. The same source links BinBencher; its primary README points to a CAMI2 toy human short-read gold-standard assembly at Zenodo 15083711, whose archive access remains unconfirmed.

AMBER [amber] provides common assignment formats and evaluation metrics. Purity is within-bin genome consistency; completeness depends on genome recovery and the evaluator's treatment of unmatched genomes. In particular AMBER 2 mean mapped-genome completeness and CAMI 1 completeness differ. A number called “completeness” without that definition is insufficient for pooling results. Marker-based MAG estimates are not identical to truth-based contig assignment metrics.

## What this review supports

It identifies protocol differences and a current citation set. It does not estimate the prevalence of poor reporting in the literature, assess all experimental sections, or rank current binners. `studies.csv` records method class, dataset extraction status, evaluation conditions and the exact source used. `not_extracted` describes this resource's extraction boundary, not an omission by authors. Primary full-text/supplement review, broader database searches and independent screening are the next steps once network access is available. Full bibliography: `bibliography.bib`.
