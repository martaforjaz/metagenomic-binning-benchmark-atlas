# Provenance and access limitations

The private workbook is identified by SHA-256 in `data/historical/workbook_manifest.json`. Every historical field points to a sheet/cell. Scientific tables are extracted without importing administrative attachments. Earlier versions are preserved separately and not multiplied into the dataset count. Curation changes are deterministic in `scripts/curate.py`; original assertions remain available even when flagged.

Primary repository retrievals on 5 November 2026 are documented with full commit, immutable README URL and content hash in `data/curated/sources.csv`. Successful Git clone and local content inspection establish that documentation was accessible at that time. They do not establish that linked articles, supplements or archives were accessible or complete. DOI strings are checked against those sources; publisher resolution has not been independently verified. Short quotations support provenance and are attributed; full external READMEs are not redistributed.

`data/curated/access_checks.csv` separates actual successful reads, denied operations and unattempted archive checks. Europe PMC and publisher HTTPS requests were denied at proxy CONNECT, before article metadata could be retrieved. GitHub API calls also returned Forbidden, while native Git reads work. Missing token variables are not used to diagnose this: the existing platform authentication is retained. Additional domain requirements are saved in the environment draft; saving a draft does not activate network access or publish an environment.

Experiment inputs are distinct artifacts from the historical catalog. `experiments/inputs.sha256.json` gives exact paths, bytes and checksums from the immutable AMBER source. Successful parsing, SampleID equality, unique IDs and prediction-to-truth sequence membership validate suitability for this narrow evaluation, not broader biological realism. `results/run.json` and `experiment.log` record execution; only subprocess wall time was measured. Upstream third-party fixtures are fetched, not redistributed.

All percentages state a unit and denominator. No blank in the historical table is interpreted as poor reporting in a paper. No completeness, quality or current-method superiority is inferred from archive availability. Catalog relation integrity and physical input identity are independently checked. Remaining scientific uncertainties are explicit and are not resolved by making the site look complete.

The independent extension was prepared with AI coding/research assistance at the author’s request. Evidence boundaries, generated results, tests and execution records are explicit so the work can be independently inspected; no human full-text screening or supervisor approval is implied.
